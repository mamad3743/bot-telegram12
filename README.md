# فروشگاه VPN - بات تلگرام (سبک MirzaBot / Faxima)

بات فروش سرویس VPN با کیف پول، خرید سرویس، دعوت دوستان، پشتیبانی و پنل ادمین ساده.

## نکته‌ی مهم درباره‌ی رنگی بودن دکمه‌ها

دکمه‌های معمولی تلگرام (Bot API / InlineKeyboard) **پس‌زمینه‌رنگی ندارن** — این قابلیت
Bot API نیست. برای اینکه دقیقاً مثل عکسی که فرستادی (سبز/آبی/قرمز) بشه، منوی اصلی به‌صورت
یک **Telegram Mini App** (صفحه‌ی HTML/CSS) پیاده شده که وقتی روی دکمه‌ی
«🚀 باز کردن منوی فروشگاه» بزنی، داخل خود تلگرام باز میشه.

رنگ‌ها رو از فایل `webapp/style.css` (بالای فایل، بخش `:root`) به‌راحتی عوض کن:

```css
--color-green:  #2ea043;
--color-blue:   #3b6fd6;
--color-red:    #d9463f;
```

زیرمنوها (پلن‌ها، کیف پول، سفارش‌ها و...) با دکمه‌ی شیشه‌ای معمولی تلگرام ساخته شدن چون
نیازی به رنگی بودن نداشتن؛ استایلشون توی `keyboards.py` هست.

## ساختار پروژه

```
vpn-shop-bot/
├── main.py           # اجرای بات + سرور aiohttp برای webhook و سرو کردن Mini App
├── config.py         # تنظیمات از Environment Variables
├── database.py       # دیتابیس SQLite (کاربر، پلن، سفارش، تراکنش)
├── keyboards.py       # دکمه‌های شیشه‌ای زیرمنوها
├── vpn_provider.py    # اینجا رو به پنل VPN واقعیت (Marzban/3x-ui/Hiddify) وصل کن
├── webapp/
│   ├── index.html     # منوی رنگی اصلی
│   ├── style.css       # رنگ‌ها اینجان - راحت قابل تغییر
│   └── app.js
├── requirements.txt
├── Procfile
├── railway.json
└── .env.example
```

## راه‌اندازی محلی (تست قبل از دیپلوی)

```bash
pip install -r requirements.txt
cp .env.example .env   # و مقادیرش رو پر کن
export $(cat .env | xargs)   # یا از python-dotenv استفاده کن
python main.py
```

اگه `PUBLIC_URL` رو خالی بذاری، بات به‌صورت polling (بدون وب‌اپ رنگی، با منوی جایگزین
دکمه‌ای) اجرا میشه — چون Mini App به آدرس HTTPS عمومی نیاز داره.

## دیپلوی روی Railway

1. یک ربات جدید با @BotFather بساز و توکنش رو بگیر.
2. یک پروژه‌ی جدید توی [railway.app](https://railway.app) بساز و این ریپو/فولدر رو
   بهش وصل کن (یا با Railway CLI: `railway up`).
3. توی تب **Variables** پروژه، متغیرهای زیر رو ست کن (طبق `.env.example`):
   - `BOT_TOKEN`
   - `BOT_USERNAME`
   - `ADMIN_IDS`
   - `CARD_NUMBER`, `CARD_HOLDER`
   - `REFERRAL_BONUS`
4. اولین دیپلوی رو بزن. بعدش از تب **Settings → Networking** یک دامنه‌ی عمومی
   (`*.up.railway.app`) بساز/کپی کن.
5. اون دامنه رو با `https://` به متغیر `PUBLIC_URL` اضافه کن (بدون اسلش آخر) و
   دوباره دیپلوی کن (Redeploy). از این لحظه بات به‌صورت خودکار webhook رو ست می‌کنه
   و Mini App رنگی هم روی همین دامنه سرو میشه.
6. با BotFather دستور `/setdomain` یا `/mybots → Bot Settings → Menu Button` رو هم
   می‌تونی برای دسترسی راحت‌تر به Mini App تنظیم کنی (اختیاری).

## وصل کردن به پنل VPN واقعی

فعلاً `vpn_provider.py` یه کانفیگ **نمونه** برمی‌گردونه. برای فعال شدن واقعی، تابع
`provision_vpn_account` رو با API پنل خودت (Marzban / 3x-ui / Hiddify و...) پر کن؛
راهنماش توی همون فایل نوشته شده.

## دستورات ادمین

- `/addplan عنوان|دسته|روز|گیگ(0=نامحدود)|قیمت`
  مثال: `/addplan ۱ ماهه|🇩🇪 آلمان|30|30|90000`
- `/stats` — آمار کاربران، سفارش‌ها و تراکنش‌های در انتظار

## جریان شارژ کیف پول (کارت‌به‌کارت)

1. کاربر مبلغ رو انتخاب می‌کنه → شماره کارت نشون داده میشه.
2. کاربر عکس/متن رسید رو می‌فرسته → برای ادمین (`ADMIN_CHAT_ID` یا اولین `ADMIN_IDS`)
   با دو دکمه‌ی ✅ تأیید / ❌ رد فوروارد میشه.
3. با تأیید ادمین، مبلغ به کیف پول کاربر اضافه میشه و اگه با لینک دعوت اومده بود،
   به معرفش هم پاداش تعلق می‌گیره.

## چیزهایی که خودت باید کامل/سفارشی کنی

- درگاه پرداخت آنلاین واقعی (زرین‌پال و غیره) به‌جای کارت‌به‌کارت دستی، در صورت نیاز.
- اتصال واقعی به پنل VPN در `vpn_provider.py`.
- متن‌های راهنما/درباره‌ما در بالای `main.py` (`GUIDE_TEXT`, `ABOUT_TEXT`).
- رنگ و آیکون‌های منو در `webapp/style.css` و `webapp/index.html`.
